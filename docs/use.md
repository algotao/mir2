# 热血传奇（PC 原版 1.76 / 怀旧服）操作方式

**核心模式：鼠标为主，键盘快捷键为辅，纯点选式 ARPG，没有 WASD 移动**（这是传奇最标志性特点！）热血传奇

## 🖱️ 鼠标基础操作

- **左键**：行走；点击怪物攻击；拾取地上物品；点击 NPC 对话
- **右键**：**跑动**（点地面就跑）；查看物品信息；法师 / 道士放锁定类技能（比如火符、冰咆哮）
- **Shift + 左键**：**强制攻击**（PK 核心！和平模式下，按住 Shift 左键强行打玩家）
- **Ctrl + 左键**：跑动（部分版本兼容，早期原版只用右键跑）
- **Ctrl + 右键**：查看玩家 / 怪物属性面板
- **Alt + 右键**：挖肉、挖尸体爆物（打鹿、猪，死后 Alt + 右键挖肉）
- **双击**：背包里双击使用药水、穿戴装备

> 
> 重点：**移动没有 WASD**，全程鼠标点地面行走 / 跑动。

## ⌨️ 核心快捷键（原版经典）

- F1~F8：自定义技能快捷键（火符、烈火、魔法盾、冰咆哮等）
- F9：包裹（背包）
- F10：人物属性 / 装备窗口
- F11：技能列表
- F12：游戏内挂（内挂，自动喝药、捡物、显示血条）
- Ctrl+H：切换攻击模式（和平 / 编组 / 行会 / 全体 / 善恶，PK 必用）
- Alt+W：鼠标悬停玩家，一键组队
- Alt+S：添加黑名单
- Alt+X：退回角色选择界面（死亡回城常用）
- Tab：小地图开关
- M：大地图
- 数字键 1~6：快捷放药水、卷轴（回城卷、随机卷），取决于在快捷位置放了什么物品

## 聊天操作

- 按回车打开输入框；
- `!` 开头 = 全服喊话；`!~`行会频道；普通文字附近聊天。

# 原版 1.76 热血传奇出生地（比奇省，随机二选一）

**两个新手村，新建角色会随机出生在其中一个，不分职业**热血传奇

1. **银杏山谷（银杏村）**
地图：比奇省，坐标大约 **648, 624**（村内安全区）
标志性：巨大银杏树，屠户、药店、精武馆，出门就是鸡、鹿。
2. **边界村（边境村）**
地图：比奇省，坐标大约 **288, 615**（村内安全区）
标志性：村口桃树，同样有屠夫、杂货铺，怪物也是鸡、鹿、稻草人。

> 
> 两个村子都属于**比奇省**，是安全区，出生自带：布衣、木剑、蜡烛，1 级。

原版 1.76：**战士 / 法师 / 道士出生点完全一样，只是随机分配银杏山谷 or 边界村**，不存在职业专属出生地。

# 分辨率

- **1024×768（基准，2026-10-09 起）**：世界**原生**按 1024×768 渲染（视口 ±12 格），
  登录/选角那套 800×600 素材**整屏拉伸 1.28 倍铺满**（跟官方客户端一样，见 D-52；
  字**不跟着位图拉** —— 按 `UI_PX × 1.28` 重新光栅化）。
- 1280×960（视野更大）
- 1600×1200（视野最大）
支持窗口 / 全屏切换，全是 **4:3**，原生没有 16:9（1080p）宽屏选项。

⚠️ 启动尺寸用 `MIR2_WINDOW=<宽>x<高>` 指定；**不小于 1024×768**（比它小会把版式缩小）。
⚠️ 屏幕可用区域（去掉菜单栏/任务栏）装不下 1024×768 时，窗口自动夹进去，画面按 **1:1 画、
多出的边裁掉** —— 不缩小、不拉伸（D-52 第 4 条）。
⚠️ 800×600 是**原版**那一档，我们这套素材的 HUD 面板只有 800 宽 ⇒ 不作为基准分辨率
（原版 1024 用的是 `Prguse[2]`，本套是空图号，所以我们"左右 1:1、中间拉宽"，见 D-50）。
